Nếu không dùng YouTube, chép file video vào thư mục này (ví dụ phim-cuoi.mp4)
rồi điền video.src: "assets/video/phim-cuoi.mp4" trong assets/js/config.js.

Khuyên dùng YouTube: file mp4 thường nặng, làm thiệp mở chậm trên điện thoại
(GitHub Pages còn giới hạn mỗi file tối đa 100 MB).
Nếu vẫn dùng file: xuất video H.264 (mp4), 720p, dưới khoảng 50 MB.
