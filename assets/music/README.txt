Chép file nhạc nền vào thư mục này và đặt tên nhac-nen.mp3
(hoặc đổi đường dẫn music.src trong assets/js/config.js).

Gợi ý: dùng file mp3 128 kbps, dài 2–4 phút, dung lượng dưới 5 MB để thiệp mở nhanh trên điện thoại.
Chỉ dùng bài nhạc bạn có quyền sử dụng.
Không muốn có nhạc: đặt music: null trong config.js.
